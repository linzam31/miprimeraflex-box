Estructura y Sintaxis

CSS funciona mediante reglas de estilo que indican al navegador cómo presentar y dar formato a los documentos HTML.

  • Selector: Apunta al elemento HTML que deseas estilizar (ej: h1, p, .clase).
  • Declaración: Contiene una o más parejas de propiedad y valor separadas por dos puntos.

Componentes de una Regla

La anatomía básica de un bloque de código CSS se compone de:

  1. Selector: Identificador del elemento en el DOM.
  2. Llaves {}: Delimitan el bloque de código de la regla.
  3. Propiedad: El aspecto visual a modificar (ej: color, background).
  4. Valor: El parámetro aplicado a la propiedad (ej: blue, 15px).

Métodos de Inserción

Las reglas de sintaxis CSS se pueden incorporar en un documento HTML de tres formas principales:

  • Externo: Mediante la etiqueta <link> conectando un archivo .css.
  • Interno: Usando un bloque <style> dentro del <head>.

Estilos en Línea

Aplicación directa:

  • Se usa el atributo style directamente en la etiqueta HTML.
  • Ejemplo: <p style="color: red;">

Comentarios en CSS

Permiten documentar el código y desactivar líneas temporalmente sin borrarlas.

Sintaxis de Comentarios

  • Se escriben encerrados entre /* y */.
  • Ejemplo: /* Esto es un comentario */
  • Son ignorados por el navegador al renderizar.
