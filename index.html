Estructura y Sintaxis

CSS funciona con reglas de estilo. Cada regla le dice al navegador cómo debe verse un elemento HTML.

  • Selector: A quién se aplica (ej: h1, p, .clase).
  • Propiedad: Lo que vas a cambiar (ej: color).
  • Valor: El nuevo resultado (ej: red).

Niveles de Especificidad

Es el sistema de puntos que usa el navegador para saber qué regla aplicar si se cruzan:

  1. Etiquetas (h1, p): 1 punto
  2. Clases (.boton): 10 puntos
  3. IDs (#menu): 100 puntos
  4. Estilos en línea (style=""): 1000 puntos

Pseudo-clases (:)

Dan estilo según el estado del elemento:

  • :hover (al pasar el cursor)
  • :active (al hacer clic)

Pseudo-elementos (::)

Modifican partes específicas:

  • ::before (contenido antes)
  • ::after (contenido después)

Box Model

En CSS todo elemento es una caja rectangular que tiene 4 capas.

Capas del Box Model

  • Content: Texto o imagen.
  • Padding: Espacio interno.
  • Border: Borde.
  • Margin: Espacio externo.
