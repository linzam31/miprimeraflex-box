¿Qué es la Especificidad?

Es el sistema de puntos que usa el navegador para decidir qué regla CSS gana cuando dos o más selectores apuntan al mismo elemento.

Siempre se aplica el estilo del selector que tenga mayor jerarquía.

Orden de Jerarquía (De mayor a menor peso)
1. !important Máxima prioridad
2. Estilos en línea (style="") 1000 pts
3. Selectores de ID (#id) 100 pts
4. Clases y Pseudo-clases (.clase) 10 pts
5. Etiquetas y Pseudo-elementos (p, div) 1 pt

Los 4 Niveles de Puntaje

1000 puntos

Estilos en Línea

Se escriben directamente dentro de la etiqueta HTML usando el atributo style.

Ejemplo: <p style="color: gold;">

100 puntos

Identificadores (ID)

Selectores únicos que empiezan con numeral. Tienen mucha más fuerza que una clase.

Ejemplo: #menu-principal

10 puntos

Clases y Pseudo-clases

Incluye clases, atributos y estados como :hover o :focus.

Ejemplo: .tarjeta

1 punto

Etiquetas

Selectores generales de elementos HTML y pseudo-elementos como ::before.

Ejemplo: h1, p, div

Ejemplos de Suma de Puntos

Selector Simple

div p

Tiene 2 etiquetas (1 + 1).

Total: 2 puntos
Selector Combinado

.caja p

Tiene 1 clase (10) + 1 etiqueta (1).

Total: 11 puntos
Selector Específico

#header .activo

Tiene 1 ID (100) + 1 clase (10).

Total: 110 puntos

La Excepción: !important

Cuando se agrega !important al final de una propiedad, esa regla ignora la especificidad y gana sobre todas las demás.

Se recomienda usarlo solo en casos muy necesarios para no complicar el código.

Empate por Orden de Cascada

Si dos selectores tienen exactamente el mismo puntaje (por ejemplo, dos clases diferentes en el mismo botón), gana la regla que esté escrita más abajo en el archivo CSS.

El selector universal * vale 0 puntos.
