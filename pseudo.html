Estructura y Sintaxis Niveles de Especificidad Pseudo clases y Pseudo elementos Box Model

Pseudo-clases (:)

Una pseudo-clase selecciona un elemento en un estado dinámico u orden específico sin alterar el HTML.

Sintaxis: selector:pseudo-clase { propiedad: valor; }

Ejemplo habitual: cambiar el fondo de un botón cuando el mouse pasa por encima.

Pseudo-elementos (::)

Un pseudo-elemento da estilo a una parte específica de un elemento o inserta contenido virtual nuevo.

Sintaxis: selector::pseudo-elemento { propiedad: valor; }

Ejemplo habitual: poner un icono antes de un enlace o cambiar la primera letra de un párrafo.

:hover

Se activa cuando el usuario pasa el cursor por encima del elemento.

a:hover { color: red; }

:active

Aplica mientras el usuario mantiene presionado el clic sobre el elemento.

button:active { transform: scale(0.95); }

:focus

Aplica cuando un campo de texto o botón recibe el foco o selección de teclado.

input:focus { border-color: blue; }

:visited

Cambia el aspecto de un enlace que el navegador ya visitó previamente.

a:visited { color: purple; }

:first-child

Selecciona un elemento solo si es el primer hijo de su contenedor padre.

li:first-child { font-weight: bold; }

:last-child

Selecciona un elemento solo si es el último hijo de su contenedor.

p:last-child { margin-bottom: 0; }

:nth-child(n)

Selecciona elementos por su número de orden (ej. 2n para filas pares).

tr:nth-child(even) { background: #eee; }

:not()

Excluye de la regla a todos los elementos que coincidan con la condición dada.

button:not(.btn-danger) { color: white; }

:checked

Aplica estilos a casillas de verificación (checkboxes) o radios seleccionados.

input:checked + label { color: green; }

:disabled

Estiliza elementos de formulario que están desactivados por el atributo HTML.

button:disabled { opacity: 0.5; }

::before

Inserta contenido decorativo antes del contenido real del elemento.

h2::before { content: "★ "; }

::after

Inserta contenido o íconos justo después del contenido del elemento.

a::after { content: " →"; }

::first-letter

Permite estilizar de forma aislada la primera letra de un bloque de texto.

p::first-letter { font-size: 2em; }

::first-line

Aplica estilos únicamente a la primera línea visible de un texto.

p::first-line { text-transform: uppercase; }

::selection

Cambia los colores de fondo y texto cuando el usuario resalta palabras.

::selection { background: yellow; }

::placeholder

Modifica el color y la fuente del texto pista dentro de un campo de entrada.

input::placeholder { color: gray; }

::marker

Permite cambiar el color o estilo de las viñetas o números de una lista <ul> / <ol>.

li::marker { color: blue; }

Resumen

Usa : para estados (interacción/posición) y :: para subpartes o agregados visuales del elemento.
